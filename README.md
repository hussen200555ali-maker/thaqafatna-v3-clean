# ثقافتنا — منصة الثقافة العربية (لعبة + مكتبة)

منصة تعليمية ثقافية متكاملة: لعبة معرفية بـ 13 نوعاً من الألغاز عبر فصول ومراحل،
ومكتبة تراثية بفصول قراءة كاملة ومراجعات، مع لوحة إدارة شاملة.

---

## 1) التقنيات

| الطبقة | التقنية |
|---|---|
| الإطار | Next.js 16 (App Router) + TypeScript |
| الواجهة | React 19 + Tailwind CSS 4 + shadcn/ui |
| قاعدة البيانات | PostgreSQL (Supabase) عبر Prisma ORM |
| النشر | Vercel (نشر تلقائي عند الدفع إلى main) |
| الحزمة | Bun (تثبيت وتشغيل أسرع) |

## 2) متغيرات البيئة (في Vercel → Settings → Environment Variables)

| المتغير | القيمة | الغرض |
|---|---|---|
| `DATABASE_URL` | Connection Pooling (المنفذ 6543) مع إضافة `?pgbouncer=true` | اتصال الخادم وقت التشغيل |
| `DIRECT_URL` | Session Pooler (المنفذ 5432) | الترحيلات والبذر وقت البناء |

> ملاحظة: السكربتات وقت البناء (الترحيل + البذر) تتحول تلقائياً إلى `DIRECT_URL`
> لتفادي خطأ 42P05 (تعارض prepared statements على الـ Pooler المشترك).
> إن ظهر خطأ اتصال وقت البناء فالسبب غالباً `DIRECT_URL` غير صحيح — الرسالة
> في السجل تعرض المضيف والمنفذ الحقيقيين المستخدمين فتسهّل التشخيص.

## 3) التشغيل محلياً

```bash
bun install            # تثبيت الاعتماديات
bun run db:generate    # توليد عميل Prisma
bun run dev            # تشغيل http://localhost:3000
bun run lint           # فحص جودة الكود
```

## 4) سلسلة البناء على Vercel (Build Command)

```
prisma generate && prisma migrate deploy && node scripts/seed-all.mjs && next build
```

الترحيلات تُطبق ثم تُبذر البيانات (السكربتات آمنة للتكرار — تُنشئ ما ينقص فقط).
ترتيب البذر داخل `scripts/seed-all.mjs`:

1. `seed-level-1.ts` — الفصل الأول والمرحلة الأولى
2. `seed-expansion.ts` — التوسعة: 9 مراحل في 3 فصول
3. `seed-admin-library.ts` — فهرس المكتبة (تصنيفات وكتب)
4. `seed-library-content.ts` — نصوص فصول الكتب والمراجعات
5. `seed-community.ts` — لاعبون ورسائل وفريق وإعدادات
6. `seed-wave2.ts` — الموجة الثانية: 18 مرحلة في 6 فصول
7. `seed-library-wave2.ts` — 4 كتب جديدة بفصول كاملة
8. `seed-final-touches.ts` — إكمال الفصول + لاعبون إضافيون

## 5) لوحة الإدارة

تُفتح من زر **الإعدادات/لوحة التحكم** في رأس الصفحة الرئيسية (لا يوجد مسار /admin
منفصل — كل شيء مكوّن داخل الصفحة)، بعد تسجيل الدخول بنافذة الإدارة المحمية
(راجع القسم 6).

### الصفحات الـ 18 في 5 مجموعات

**عام:** لوحة التحكم — الإعدادات — سجل التدقيق — التقارير
**المكتبة:** إدارة المكتبة (مركز قيادة) — الكتب — تصنيفات الكتب — فصول الكتب — المراجعات
**اللعبة:** فصول اللعبة — محرر المراحل — تحدي اليوم — مدقق الجودة — موازنة الصعوبة — شجرة المهارات
**المجتمع:** اللاعبون والقراء — الرسائل — الأدوار والصلاحيات
**النظام:** (ضمن الإعدادات)

### سير عمل تحدي اليوم

- **السؤال:** سؤال واحد يوميًا بتوقيت الرياض، يُختار بثبات من بنك الإدارة حسب التاريخ (أو يُثبَّت يدويًا من صفحة «تحدي اليوم»).
- **الأمان:** نسخة المتصفح بلا إجابة ولا شرح — `correctIndex: -1`، `answer` فارغ و`explanation` محذوف (قد يفشي الشرح الإجابة)؛ التحقق والمكافأة والشرح تتم في `/api/daily-challenge/answer` فقط.
- **الجلسة:** رمز HMAC مرتبط بالجهاز والتاريخ والسؤال، بصلاحية ١٢ ساعة و٥ محاولات كحد أقصى.
- **المكافأة:** تُمنح مرة واحدة عبر `RewardLedger`، والرصيد السيرفر هو الحقيقة المعروضة.
- **الأنواع المؤهلة:** `text` و`multiple` فقط (لا تُرسل إجابة الأنواع الأخرى للمتصفح).
- **الإدارة:** إضافة/إيقاف أسئلة، تثبيت سؤال يوم، مكافأة مخصصة، ومراجعة آخر الجلسات — مع قيد تدقيق لكل عملية.

### سير عمل المكتبة

- **إضافة كتاب:** إدارة المكتبة → الكتب → «كتاب جديد» → عنوان (إلزامي) + مؤلف + وصف + تصنيف + حالة (منشور/مسودة)
- **فصول الكتب:** إدارة المكتبة → الفصول → اختر الكتاب → «فصل جديد» → عنوان + محتوى (حتى 20,000 حرف، فصل بين الفقرات بسطر فارغ)
- **التصنيفات:** إضافة/تحرير حر — الحذف ممنوع إن كان به كتب (انقل الكتب أولاً)
- **حالات الكتاب:** منشور (يظهر للقراء) أو مسودة (تُحفظ دون ظهور)

### سير عمل اللعبة

- **تحرير مرحلة:** محرر المراحل → اختر المرحلة → عدّل حقولها التعريفية أو ألغازها
- **13 نوع لغز:** text, image, images4, emoji, scrambled, crossword, fillblank,
  matching, multiple, audio, logic, progressive, mixed
- **إنشاء فصول/مراحل جديدة:** حالياً عبر البذر (سكربتات) — الواجهة تدعم تحرير
  الموجود بالكامل، وإضافة فصول اللعبة من الواجهة ضمن خطة التطوير القادمة

## 6) الأمان — مصادقة لوحة الإدارة

لوحة الإدارة وكل مسارات `/api/admin/*` محمية بجلسة موقّعة (HMAC) عبر `src/proxy.ts`.
فتح زر «لوحة التحكم» في تطبيق اللاعب يعرض نافذة دخول أولاً، ولا تُعرض الواجهة
إلا بعد تحقق الخادم من الكوكي.

### الإعداد في Vercel (إلزامي)

| المتغير | مثال | ملاحظة |
|---|---|---|
| `ADMIN_PASSWORD` | قيمة عشوائية طويلة | إلزامي — بدونه تُرفض كل طلبات الإدارة (Fail-Closed) |
| `ADMIN_USERNAME` | `admin` | اختياري — الافتراضي `admin` |
| `ADMIN_SESSION_SECRET` | نص عشوائي ≥ 16 حرفاً | اختياري — يُشتق من كلمة المرور إن غاب |
| `DAILY_SESSION_SECRET` | نص عشوائي ≥ 16 حرفاً | اختياري لتوقيع جلسة التحدي اليومي — يُشتق من `ADMIN_SESSION_SECRET` ثم `ADMIN_PASSWORD` إن غاب |

الجلسة مدتها ٨ ساعات، والكوكي `httpOnly` و`SameSite=Lax` وفي الإنتاج `Secure`.
للخروج: `POST /api/admin/logout`. حالة الجلسة: `GET /api/admin/session`.

## 7) النسخ الاحتياطي والاستعادة (Supabase)

```bash
# نسخة احتياطية — من جهازك (استخدم DIRECT_URL من إعدادات Vercel)
pg_dump "<DIRECT_URL>" -F c -f backup-$(date +%F).dump

# استعادة إلى قاعدة جديدة (فارغة أولاً)
pg_restore -d "<DATABASE_URL_الجديدة>" --no-owner --no-privileges backup-YYYY-MM-DD.dump
```

> عبر Session Pooler (5432) وليس Transaction Pooler — الأخير لا يدعم كل عمليات النسخ.

## 8) مسارات API العامة — جاهزة لتطبيق Flutter

### اللعبة
| المسار | الوصف |
|---|---|
| `GET /api/levels` | خريطة المراحل بالفصول |
| `GET /api/levels/[id]` | تفاصيل مرحلة بألغازها |
| `GET /api/leaderboard` | المتصدرون |
| `GET /api/daily-challenge?deviceId=...` | سؤال تحدي اليوم — بلا إجابة، مع رمز جلسة موقّع |
| `POST /api/daily-challenge/answer` | التحقق السيرفي والمكافأة (الجسم: `{token, answer}`) |
| `GET /api/recommendation` | توصية ذكية (5 أسئلة) |
| `POST /api/players/sync` | مزامنة ملف اللاعب |

### المكتبة
| المسار | الوصف |
|---|---|
| `GET /api/library` | فهرس المكتبة (تصنيفات + كتب) |
| `GET /api/library/books/[id]` | كتاب بفصوله كاملة |
| `GET /api/library/reviews` | مراجعات القراء المعتمدة |

### عام
| المسار | الوصف |
|---|---|
| `GET /api/settings` | إعدادات المنصة |
| `POST /api/support` | إرسال رسالة دعم |

**الإدارة** (`/api/admin/*`): books, categories, book-chapters, chapters, levels,
puzzles, players, reviews, messages, team, quality, audit, stats, skill-tree, settings,
`daily` (بنك الأسئلة والجدول والجلسات) — كلها سليمة ومختبرة ومحمية بالمصادقة.

## 10) استكشاف الأخطاء السريع

| المشكلة | الحل |
|---|---|
| `42P05 prepared statement already exists` | تأكد أن البذر يمر عبر DIRECT_URL — مضمون تلقائياً في seed-all.mjs |
| `P1001 can't reach database` | تحقق من DATABASE_URL / DIRECT_URL — السجل يعرض المضيف:المنفذ الحقيقي |
| تحرير عنصر غير موجود يُعيد 500 | إن ظهر بعد تحديث Prisma مستقبلاً: الدالة `isRecordNotFound` في `src/lib/prisma-errors.ts` تفحص `error.code === "P2025"` — لا تعتمد على نصوص الرسائل أبداً |
